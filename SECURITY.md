# Security Policy

## Supported Versions

Security fixes are applied to the latest revision in this repository.

## Reporting a Vulnerability

Please do not open a public issue for suspected security problems.

Instead, report the issue privately to the repository owner with:

- A short description of the problem
- Steps to reproduce it
- Impact assessment
- Any suggested mitigation

The project does not intentionally collect credentials, passwords, cookies, or external telemetry. If you find behavior that violates that expectation, report it as a security issue.
